# Showcase tabs (`showcase-tabs`)

A row of tab pills that crossfade between 16/9 images with a one-line note. With no JS the first image shows and every note is listed.

- Pages: "build"
- Island: Yes: `island.ts` (role=tablist, arrow keys, GSAP crossfade)
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
