# The hopper (`hopper`)

Failures gimmick: failed builds as tiles around a hopper. Drag one in, tap it, or focus it and press Feed it in; the hopper prints a slip. A plain list of slips with reduced motion.

- Pages: "failures"
- Island: Yes: `island.ts` (mounted with `onPage`, reduced-motion fallback in CSS)
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
