# Chronos day runway (`chronos-runway`)

The interactive day runway and usable-time reading from the Chronos page. Drag the draft block, use its arrow keys or the two presets; the longest open stretch and total unassigned time update. Pure maths in `day.ts` (tested). The fictional Studio North schedule lives in code; every label and sentence is a field.

- Pages: "build"
- Island: Yes: `island.ts` (pointer drag, keyboard, presets; CSS transitions only)
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
