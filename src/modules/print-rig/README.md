# The print rig (Still printing) (`print-rig`)

About gimmick: a rod-and-clamp rig printing a figure of Josef, one layer per published milestone. Shows the current print state with reduced motion.

- Pages: "about"
- Island: Yes: `island.ts` (mounted with `onPage`, reduced-motion fallback in CSS)
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
