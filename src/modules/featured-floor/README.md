# Featured builds floor (`featured-floor`)

The Home floor: featured builds scattered on granite; scrolling pans the camera from build to build. Vertical list on phones and with reduced motion.

- Pages: "home"
- Island: Yes: `island.ts` (mounted with `onPage`, reduced-motion fallback in CSS)
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
