# Devlog entry layout (`devlog-entry`)

One devlog entry: title, date, build tag, hero photo, body paragraphs and images, Fuse note, build link, previous and next. The entry itself is edited under Devlog entries.

- Pages: "devlog"
- Island: No: zero JavaScript
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
