# Showcase media (`showcase-media`)

Heading, body and link above a 16/9 poster with an optional short video (click to play, preload none, native controls) and a caption.

- Pages: "build"
- Island: Yes: `island.ts` (click-to-play via components/Video.astro)
- Fields and defaults: `module.ts`. Render: `View.astro` (scoped styles, tokens only).
